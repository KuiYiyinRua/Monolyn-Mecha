# 驮运机甲的远征队选择

不朽、巨像、掠夺者、禁断者在组建、重新组建及拆分远征队的动物列表中显示。空舱、有人驾驶、机械师控制三种状态均可选择，机械师不必同行。原版仍要求至少一名在队伍中的殖民者带队；舱内驾驶员不替代该要求。

载重维持 500 / 800 / 2000 / 600 kg，沿用已有的集结移动、光芒消耗、世界速度及安全入图逻辑。出发前需有足够光芒。此修订不增加存档字段，更新后需要重启游戏；联机各端使用相同文件。

## 原因与修改范围

在已安装的 RimWorld 1.6.4850 rev645 上，`CaravanFormingUtility.AllSendablePawns` 已允许这些机甲加入候选名单。但 `CaravanUIUtility.AddPawnsSections` 的动物分组要求 `Pawn.IsAnimal`，机械体分组要求 `OverseerSubject.State == Overseen`。机甲的机械血肉类型使第一项不成立，空舱未绑定或有人驾驶时第二项也不成立，因而没有可见条目。

`Source/Caravan.cs` 只替换该界面的两个分组谓词：四种驾驶机甲进入动物分组，同时从机械体分组排除，避免绑定状态下重复显示。原版动物、机械体及本模组追猎者／守护者的分类维持原逻辑。不会全局修改 `Pawn.IsAnimal`、`Pawn.IsColonyMech`、机械师关系或战斗逻辑。

另外，组队界面的 `Notify_TransferablesChanged` 会强制使护卫模式机械体与其机械师的勾选状态一致。四种驮运机甲也在这个局部判断及相应缺机械师警告中排除，使玩家的选择能够保留。

货物仍由原生集结作业装载，机甲实际步行至出口，由原生远征队流程离图、旅行及返营。大型机体返回时沿用已发布的 `MechaCaravanLanding` 完整占地检查。没有新增同步命令，继续使用 Multiplayer 原有的组队会话和世界移动同步。
