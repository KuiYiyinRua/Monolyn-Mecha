# 巨像

RimWorld 1.6，Monolyn: Mecha 0.3.0。需要 Harmony 与墨诺灵本体；不依赖航母模组。复用不朽的真实驾驶员容器、光芒网络、相位护盾、驮运和迁移逻辑。

## 数值与制造

| 项目 | 数值 |
|---|---|
| 结构生命 | 300；没有不朽的单次 50 伤害上限 |
| 护盾 | 100；本体炮塔相位护盾，隐藏地图上的护盾圈、拦截扇形与停机标记，保留护盾状态条 |
| 地面范围 | 3×3；贴图高于地面范围 |
| 地图速度 | 固定 8 格/秒，穿越墙体、障碍和深水等地形，不受减速影响 |
| 载重 | 800kg，可骑乘、驮运 |
| 世界速度 | 基础 35 格/天；单人配一台巨像按 1.6 倍骑乘约 56 格/天（1071 tick/格），[骑乘规则与验证](CaravanRiding.md) |
| 能源容量 | 10000 光芒，仅使用光芒 |
| 驾驶待机 / 行走 | 每秒 2 / 4 光芒 |
| 世界行走 | 每游戏日 1200 光芒 |
| 制造 | 300 炼锻钢、6 灵脉回路、50 种子、50000 光芒、96 游戏小时 |
| 研究 | 墨诺灵科技树“巨像战甲”，28000 信息；前置“不朽战甲”与“引力控制” |

在已调谐机械师的原生“构造体塑造所”内选择“打印：巨像”。驾驶不占机械师带宽。选择巨像后使用“进入驾驶舱”，由殖民者走近并登乘。右键地面移动，右键敌人或“攻击”按钮选择射击目标；移动命令不会取消巨像正在执行的扫射。停止按钮同时停止移动和攻击。

“装载货物”允许殖民者搬入最多 800kg 货物。组建远行队前让驾驶员下机，在原版远行队窗口同时选择殖民者和巨像，即可使用骑乘和驮运能力；过载等原版出发限制仍然生效。空舱停放不扣待机光芒，补盾仍按原生规则消耗能源。

## 双束横扫

对照用户视频：左右两个高位发射器同时发出持续光束，落点从目标两侧向相反方向横扫并交叉。锁定开火时的目标位置，横扫宽度约 6 格。复用本体 `Mote_LargeBeam`、`SupressionBeam_End`、`Fleck_BeamBurn`、`Supression_Shooting`；不额外生成弹道、命中或音效素材。

- 射程 38 格，最小射程 4 格；瞄准 0.6 秒，持续横扫 0.9 秒，扫射后冷却 1.1 秒。
- 每束光束对本轮扫过的同一个实体只结算一次 12 点伤害，穿甲 60%；两束均扫中时共 24 点。多格建筑不会因占多个格子被同束重复结算。
- 每轮两束共消耗 120 光芒；准星准备阶段不扣射击能源。移动射击仍消耗行走能源。
- 移动时发射器跟随机身，已开始的横扫落点保留在地面。穿墙行走不等于穿墙射击：墙体仍会挡住光束，扫到友军会误伤。
- 缺少驾驶员、驾驶员失去行动能力或光芒耗尽时取消攻击；空载不会自动开火。

## 光芒、迁移与保存

使用本体光芒存储、接收器与分配器补能，选中后显示光芒状态及护盾状态条（不绘制地图护盾圈）。相位护盾每消耗 250 光芒恢复 25 点；保留本体微量自然回复，缺口不足 25 时不触发整批光芒补盾。破盾与 EMP 的停机规则沿用炮塔组件。

有人驾驶或空驾驶舱均可迁移至同图可见且有光芒网络覆盖的位置，沿用 1000 tick 迁移冷却和 300 网络流量。移动同一实例，保留驾驶员、结构生命、护盾、光芒、货物和实体标识。迁移取消当前攻击动作；存档仍保存横扫计时、每束已命中的实体集合与真实驾驶员，避免读档后重复伤害。

「自动战斗」默认关闭。开启后会主动追击、保持合适距离并选择射击位置，横扫过程中可以移动。追击、后撤与换位分别保留移动意图，避免每次判断都重启路径；手动移动优先，手动攻击或停止会关闭自动战斗。

原生道路、门与建筑保持原状；穿行只对巨像自己的路径和移动计时生效。巨像没有穿梭发射功能。
