# 墨诺灵敌袭机甲（0.7.0）

本扩展仅向 `UrielCult` 和与玩家敌对时的 `RaphaelCult` 战斗袭击加入六种机甲。其他种族派系、友好增援、商队护卫、据点驻军均不加入。六种 PawnKind 同时禁止原版机械集群和猎杀人类动物事件抽取。

本体的 `Entities_Rust`（锈蚀）是特殊实体派系，设置了 `raidsForbidden=true`，使用 `RustMechs` 而非普通 Combat 编组；本次保留其原有事件机制。

四种驾驶战甲的点数已包含一名 `Monolyn_Rifleman`（120 点），驾驶员不会再作为独立编组选项重复收费。权重是抽取权重，不是每次袭击的出现概率；系统只从满足条件的候选中随机抽取。

机甲合计最多消耗编组预算的 50%，按实际选项成本计算，保留原版总预算、派系单体点数曲线与数量限制。表中的预算是额外下限；原派系曲线仍可能阻止低点数编组选择守护者或追猎者。实际编组点数也可能与故事叙述者最初的事件点数不同。

这些值按机体耐久、护盾、武器范围和范围伤害、移动与补盾能力分档；当前验证保障生成及行为正确，长期战役的难度仍需实际游玩反馈。

## 驾驶、能源与队伍

敌袭驾驶员为同派系、健康成年且可战斗的真实墨诺灵，直接装入现有驾驶舱容器。驾驶员的身份、装备和机体一同保存。离舱或机体毁坏时，存活驾驶员加入原袭击队伍；重新登机时从地图队伍移除，避免同时成为机组和独立队员。

敌袭战甲首次生成时装满自身光芒，掠夺者装填 8 枚导弹并启用原有自动制弹。射击、行走和制弹继续支付原有资源成本；重复准备和读档不补充资源，也不重复生成驾驶员。敌方守护者携带独立的 600 光芒补盾储备，消耗与余量写入存档。

敌机不能注册到玩家光芒分配器，也不能从玩家光芒网络抽取资源。玩家制造仍保留空驾驶舱、掠夺者空弹仓、自动战斗默认关闭的原有行为。

普通进攻使用本扩展的追击、射击与守护者支援逻辑，追猎者可沿路径闪现。巨像使用原有移动横扫；禁断者维持光球时保持原地。破墙、集结、护卫和撤退继续服从袭击队伍的职责。
