# 禁断者光球与碰撞显示修订

2026-10-15，RimWorld 1.6.4850 rev645。修改已安装到本 mod 目录；重新启动游戏后加载。

## 最终设定

- 光球速度为 **8 格/秒**，使用世界坐标按 tick 推进，不读取 Pawn 移动速度或地形寻路费用。
- 光球持续 **300 ticks（5 秒）**；期间保持移动锁定，结束后的恢复仍为 300 ticks。
- 单次消耗 180 光芒、伤害频率、每秒伤害、爆炸伤害和射程沿用原值。
- 中、日、英、法、俄的攻击说明及机体说明已同步更新。

## 显示问题与修复

`Pawn_Disruptor.DrawPos` 原先在原生位置平滑之后才添加占格中心偏移。2×2 机体转向时，原生占格中心会随朝向改变，因此这段未经过插值的偏移会让贴图立即换位。重叠单位的原生视觉挤开偏移，以及甲瓣角度额外叠加机体朝向，又放大了跳动。

原版实机对照中，在与殖民者重叠时改变朝向，同帧机体中心跳动 1.414214 格，甲瓣最大跳动 2.361652 格；实际穿过占用格并绕墙的路径中，最大单帧位移为 1.000418 格。

现在占格中心在 `PawnTweener.TweenedPosRoot` 内计算，再交给原生平滑处理。禁断者不再使用单格 Pawn 的视觉挤开偏移，甲瓣使用独立于行进朝向的连续旋转相位。物理占格、原生单位碰撞、完整机体避障及战斗坐标计算保持原有逻辑。

最终同场景的机体中心和甲瓣同帧跳动均为 0；路径最大单帧位移为 0.08346176 格。该帧间指标来自本次正常速度运行，不作为所有硬件帧率或游戏倍速下的上界。

同类检索还发现 `Pawn_Reaver.DrawPos` 在插值后增加占格偏移；本次没有验证掠夺者是否出现同样症状，修改范围限定为用户报告的禁断者。其他线程对掠夺者和武器的同期修改已包含在最终冻结源码中，没有用初始备份覆盖。
