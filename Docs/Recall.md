# 远征入图修复与机械师折跃

## 使用

六种机械体（不朽、巨像、掠夺者、禁断者、追猎者、守护者）均增加“折跃至机械师”按钮。选中机械师还可通过“召回机械体”菜单选择其已绑定单位，包括远行队成员和旧故障遗留的世界 Pawn。

- 同地图扣除自身满容量的 30%；跨地图、远行队和世界单位扣除 50%。不是按当前剩余量打折。
- 四种战甲使用光芒；追猎者、守护者使用其原有构装体能源。
- 机械师必须存活、位于地图上，并保留该单位的实际绑定关系。
- 机械师周围 8 格内搜索可容纳完整机体的安全落点。能源不足、无落点或绑定已失效时不移动、不扣费。
- 运输、收容、驾驶员在舱内或移动锁定等状态不能召回。成功召回保留同一 Pawn、库存及控制关系，结束旧位置的作业和战斗目标。
- 正常远征入图不收取折跃费用。

## 原因与修复

已在原 DLL 上复现：原版 `CaravanEnterMapUtility.Enter` 取得单格落点后调用 `GenSpawn.Spawn`，之后无条件清空并销毁远行队。大型机械体完整占地超出地图边界时，`GenSpawn` 提前拒绝生成；原有 `SpawnSetup` 内的纠偏尚未执行。巨像、掠夺者和禁断者因此留在世界 Pawn 列表，地图上没有实体，而原机械师关系仍然存在。

修复在原版生成前验证完整占地及四种可能朝向，并确定性查找替代落点。只处理本模组机械体。极端情况下整张地图均无安全落点会明确中止，避免继续执行原版清空远行队的步骤。

折跃直接迁移原 Pawn，不将地图单位作为无主自由世界 Pawn 重新登记，避免原版世界登记逻辑改变阵营。旧故障若已被其他逻辑删除 Pawn 或解除绑定，则召回菜单无法恢复已消失的数据。

## 联机实现

按钮和菜单共用 `MechaRecall.Execute(pawnId, ownerId)`。同步整数 ID，使跨地图命令进入 Multiplayer 全局队列；执行时再次核验归属、能源及落点。UI 绘制和打开菜单不修改模拟状态。

可选 Multiplayer 适配层调用已核验的原生 `TimestampFixer.FixPawn` 转换地图时钟，修正追猎者闪烁冷却，并消费同一世界 tick 内已有的世界入图标记，避免重复转换。核心程序集不引用 Multiplayer。目标适配版本为本机 Multiplayer `0.11.5+4a3be27-dirty`。
