# 掠夺者（Reaver）

版本 0.5.1 加入掠夺者。使用同一套战甲驾驶舱、原生光芒网络、炮塔相位护盾、载货与迁移逻辑；现支持带驾驶员迁移。

| 项目 | 数值 |
| --- | --- |
| 结构生命 / 护盾 | 280 / 100 |
| 地图速度 / 世界速度 | 4 格/秒 / 固定 4 格/天 |
| 载重 | 2000 kg，可骑乘的驮兽，可由殖民者驾驶 |
| 地图占地 / 绘制 | 正背实际 2×3 格，侧向实际 3×2；可见机体补偿透明留白后匹配占地，西向镜像；地面路径检查完整机体和转向空间 |
| 弹仓 | 最多 8 枚，初始空仓 |
| 制弹 | 300 ticks（5 秒）/枚，完成时扣 150 光芒 |
| 射击 | 单发，60 ticks（1 秒）间隔，射程 45，最小射程 4.5 |
| 爆炸 | 半径 4 的圆形，16 伤害、75% 穿甲；建筑实际 48 伤害 |
| 能源 | 容量 10000；驾驶待机 1/秒，行走 3/秒，远行 1200/天 |
| 制造 | 300 炼锻钢、6 灵脉回路、50 种子、50000 光芒、96 游戏小时 |
| 研究 | 墨诺灵科技页，26000 信息知识点，前置“不朽战甲”与“重力控制” |

自动造弹默认开启，满仓停产；光芒不足或开关关闭时保留进度。无人驾驶和远行队中也能制造。弹药属于机体内部状态，发射库存弹不会再次支付制弹费用。射击需要驾驶员和光芒，移动暂停射击。

混编战甲远行队按最慢战甲的固定速度计算，因此含掠夺者时为 4 格/天。普通不朽、巨像单独远行仍为原先的 35 格/天。

迁移直接移动现有 Pawn 及其驾驶员容器，不替换机体；驾驶员、生命、护盾、光芒、货物、弹仓、制造进度和开关保留。迁移沿用 300 网络流量和 1000 ticks 冷却。原生护盾消耗 250 光芒恢复 25 点；护盾被 EMP 打断和被耗尽的行为也沿用本体。

「自动战斗」默认关闭。开启后沿适合完整机体的路径主动追击，到可射击位置后停下攻击，不主动后撤拉扯。手动移动优先，手动攻击或停止会关闭自动战斗。

导弹继承原生 `TrailProjectileNewB`，使用 `Things/Mote/Bullet_Phase`、`MNBulletImpactBase` 与游戏爆炸效果。爆炸遵循原版墙体遮挡并可能误伤友军，3 倍倍率仅作用于建筑。

三视图通过内置 image_gen 生成，源图与完整提示词保存在 `Artwork/Reaver`。当前正面 south R2、侧面 east R4、背面 north R2；西向镜像侧面。修订后的侧面遵循原参考左尾右头，右侧厚重头甲下方设发射口，拱背与机腹直接重绘体积。保留生成的原始 RGBA；运行时侧视绘制尺寸匹配横向画布。详见 [侧视修订记录](ReaverSideRevision.md)。

制造入口：研究完成后，使用已调谐的墨诺灵构装体成型机，选择“打印：掠夺者”。驾驶不占机械师带宽。选择机体会显示光芒/装甲/载重、弹仓进度、自动造弹、驾驶及原有迁移操作。

实际验证结果另见 ReaverValidation.md。未声明多人同步兼容。
