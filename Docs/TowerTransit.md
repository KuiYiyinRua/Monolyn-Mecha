# 机甲通过灯塔传送

在两座已经连接的灯塔上，使用原有的“进入”按钮选择机甲。四种驾驶机甲显示在动物分组；追猎者、守护者仍使用机械体分组。

进入条件为机内有能够驾驶的驾驶员，或机甲已绑定有效机械师。机械师可以留在原地图，机甲也能从另一座灯塔返回。机甲需有能源、能够行动，灯塔连接及网络拥堵限制沿用原模组；不额外收取机械师召回的 30%／50% 能源费用。无驾驶员且未绑定的空机仍可随远征队驮运，但不能自行进入灯塔。

传送移动原有机体，保留驾驶员容器、库存、护盾及绑定关系。出口按完整机体占地的四个朝向在目标灯塔附近寻找空地，避免偶数尺寸机体转向时侵入灯塔；找不到时留在原地图。选择完成后，执行时仍会重新检查控制与能源条件。

原模组会在单位通过时增加其质量 1.5 倍的网络负载，并使到达单位短暂眩晕。这些效果保留。大型机甲可能一次就超过默认网络容量；超载时原模组会取消其余待传送任务，需等待负载恢复或提高网络容量后重新选择。

## 修改边界

精确依据为 RimWorld 1.6.4850 rev645 和本地 `ASEL.dll` SHA-256 `71F0ADF7C8FC7F44783561CCB66FC2B10578B1D49EE5A9624F3E3C24625B2E65`。原模组未附源码，也未找到可核对的公开源码，故按安装版本反编译相关类型。

`Building_LightConduit` 继承原版 `MapPortal`。入口名单复用 `CaravanUIUtility.AddPawnsSections`；`EnterPortalUtility.MakeLordsAsAppropriate` 只收殖民者与原版受控机械体，会漏掉未绑定的有人驾驶战甲。原版出塔作业仅检查一个站立格，不能保证大型机体占地安全。

`Source/TowerTransit.cs` 仅为本模组六种机甲与 ASEL 光路入口增加候选过滤、执行时复查、入塔任务分配和安全传送作业；普通单位及其他模组的传送门继续执行原流程。四种驾驶机甲只在有效的入塔作业中允许跨地图绑定提供移动条件。

联机沿用 Multiplayer 的 `MapPortalSession`、选择数量及确认同步，不重复注册灯塔命令。跨地图生成复用既有 `MechaRecall.SpawnTransferred`，使机体及其驾驶员的时间戳转换到目标地图。没有新增生产存档字段。
