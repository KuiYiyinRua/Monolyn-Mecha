# 禁断者（Disruptor）

0.6.0 新增可驾驶的墨诺灵地面战甲，复用现有战甲真实驾驶舱、光芒网络、炮塔护盾、载货与迁移；现支持带驾驶员迁移。

| 项目 | 设定 |
| --- | --- |
| 生命 / 护盾 | 200 / 100；不继承不朽的单次 50 点伤害上限 |
| 占地 | 实际 2×2 格；装甲展开时可见体量约 2×2 格，完整机体避障 |
| 运输 | 600kg，可驾驶、驮运、远行队骑乘 |
| 移动 | 地图基础速度 6 格/秒，受普通地形影响；世界固定 30 格/天 |
| 追踪光球 | 180 光芒/次，射程 30，最小射程 5.5；光球速度 8 格/秒，不受地形减速影响，持续 5 秒 |
| 持续伤害 | 光球当前格及周围一圈共 3×3 格；每 15 ticks 造成 2 点，即 8 点/秒，45% 穿甲 |
| 结束爆炸 | 半径 5 格圆形，20 伤害、35% 穿甲，无距离衰减 |
| 敌我 / 建筑 | 两阶段均只伤害敌对 Pawn 与建筑；建筑伤害 ×3：24/秒和 60 爆炸伤害 |
| 冷却 | 光球结束后 5 秒；一台机体最多同时维持一枚光球 |
| 光芒 | 容量 8000，驾驶待机 1/秒、移动 3/秒、世界移动 1200/天，攻击额外扣费 |
| 制造 | 240 炼锻钢、8 灵脉回路、60 种子、60000 光芒、96 游戏小时 |
| 研究 | 墨诺灵科技页「禁断者战甲」，30000 信息；前置不朽战甲、重力控制 |

研究后在已调谐的「构造体塑造所」选择「打印：禁断者」。驾驶不占机械师带宽。选中后保留原生光芒 UI，并增加光球状态条和「自动发射光球」开关。自动发射默认开启，仅在驾驶员操作且机体静止时主动选择射程内敌人；关闭后仍可手动攻击。

光球独立保存当前位置、目标和已存在的 ticks，逐 tick 追踪；原目标失效时重新选择附近敌人。飞行遇实体墙体会停止推进；持续伤害检查局部视线。到时按圆形范围爆炸。5 秒时长、5 秒恢复、射程和光芒费用是本次补全的平衡参数。

维持光球时，移动按钮、右键移动、原生路径启动和迁移均被阻止。停止命令、关闭自动发射、驾驶员离开或光芒耗尽，不会取消已付费光球，也不会提前解除移动锁；光球按时结束后恢复移动。若机体被摧毁或强制移出地图，光球安全消散，不在其他地图结算爆炸。

无活动光球时，无论是否有人驾驶，都可以直接迁移现有机体到本地图光芒覆盖内的完整 2×2 空地。保留机体身份、驾驶员及货物所有权、生命、护盾、光芒、自动发射开关和武器冷却；迁移消耗 300 网络流量、冷却 1000 ticks。护盾补充沿本体炮塔规则，每 250 光芒恢复 25 点。

「自动战斗」默认关闭。开启后主动追到可发射光球的位置，不主动后撤拉扯；维持光球期间保持原有移动锁，光球结束后继续追击。手动移动优先，手动攻击或停止会关闭自动战斗。

三向球核与底托、独立甲瓣内外侧均由内置 image_gen 生成。地图实际绘制使用三向球核和独立环绕的三片甲瓣，不旋转整张身体图。三瓣先按用户反馈将宽高放大至首轮预览的 130%，再只将当时宽度增加 30%；最终为首轮预览的宽度 169%、高度 130%。球核、底托和环绕轨道保持原尺寸。有健康驾驶员时显示三瓣；驾驶且供能正常时旋转，约 8 秒一圈。无人驾驶时三瓣立即隐藏，只显示裸球核和固定底托；旋转相位仅为视觉状态，不写入存档。读档从默认相位开始，不影响武器、护盾或光芒状态。

光球与爆炸复用墨诺灵本体的 `Bullet_Disruptor`、`MNPulseBase`、`Fleck_DisruptorTrail`、`Fleck_MNSparkPulse`、`Fleck_MNSparkFlashPulse`。原始 PNG 保留实际 RGBA，项目内没有脚本改画或拉伸源图；尺寸与球心在绘制时校准。

混编远行队按最慢战甲速度行进。单机隔离验证与美术审阅记录见 `DisruptorValidation.md`、`Artwork/Review/Disruptor_review.md`；未声明多人同步验证。
