# 追猎者

追猎者在墨诺灵本体的「构造工程 II」研究完成后，于构造体成型器选择「打印：追猎者」。配方为30种子、10000光芒，制造时间180000 tick，即72个游戏小时，成型器须绑定拥有至少2空闲带宽的机械师。沿用本体的制造速度和暂停条件。

|项目|数值|
|---|---|
|带宽／体型|2／1.5|
|机体生命／护盾|150／100|
|利器／钝器／热能护甲|77%／67%／200%（轻甲；2026-10-14 平衡调整）|
|基础移动速度|9格/秒；遵守陆地路径与地形移动耗时|
|工作|搬运、清洁、灭火；使用本体工作分配页|
|运行光芒|每游戏小时30；本体自动补能开启且清醒时，每250 tick扣3光芒并补充机械能量|
|射击|每轮两发，各10伤害、35%穿甲，射程30格|
|射击节奏|瞄准0.8秒，双发内部间隔约0.1秒，整轮后冷却0.2秒|
|命中|各距离基础命中90%；保留原版天气、烟雾、目标体型、姿态、掩体及拦截影响|
|闪现|范围20.9格、冷却8秒；手动释放沿用执法者0.33秒前摇|

补能从本体光芒总池扣除，保留本体「自动充能」开关和机械能量需求。缺少光芒时，现有机械能量仍可使用，耗尽后按本体机械体逻辑停机。射击和闪现不额外扣光芒。

机体采用单一150点机架生命池，受到149点未减免伤害后仍保留1点生命，耗尽后损毁。机架不按生物器官的伤损比例提前失能；EMP和机械能量限制仍生效。

护盾直接使用本体监察者的投射物拦截及恢复机制，最大100点、每120 tick恢复1点，破盾后1800 tick重建；EMP干扰1500 tick。它拦截敌方地面射弹，不是对近战和所有伤害的统一吸收条。

选中追猎者可见两个独立开关：

- 「自动战斗」默认关闭。开启后搜索全地图可见、可达的活动敌人，主动追击，尝试在24～30格距离作战，优先选择有射界的掩体位置，并避免靠近其他敌人。死亡、倒地或失去敌对关系的目标会被放弃。狭窄地形和多方向包围可能限制走位。
- 「自动闪现」默认开启。行走时沿实际路径选择5～20.9格以内、可见且空闲的落点，以闪现代替部分行走。与手动闪现共享8秒冷却，保留当前任务、携带物和排队命令。关闭后仍能手动使用闪现。

手动移动／攻击命令及排队命令优先于自动追猎；搬运中的货物和远行队任务也优先。关闭自动战斗会立即结束本扩展的追猎任务，之后继续本体的工作／护卫模式。停机、充能、倒地、失控时不运行这套自动战斗。

征召后可以使用「双联光束投射器」按钮或右键敌人射击。投射器按本体机械体的方式作为永久主武器生成，不能卸下回收；原版手动攻击和自由开火均能使用。手动指令保留原版机械师指挥范围限制，自动追猎按地图搜索目标。

美术按用户纠正后的方向采用高弓背甲、低位墨诺灵面罩和四条细长刃足，正、背、侧为独立透明贴图，西向镜像侧面。射弹复用本体 `TrailProjectileNewB`、`Bullet_Dogma`、`DogmaMuzzle` 和 `MNBulletImpactBase`，音效复用 `MNDogma`。闪现直接调用本体 `CompAbilityEffect_SyncBlink`，只增加落点检查和自动行走时的任务保护。

三视图审核见 `Artwork/Review/Stalker_ThreeViews_review.md`；运行测试摘要见 [0.2.0 验证记录](StalkerValidation.md)，原始证据在 `BuildValidation/Stalker-*`。未进行 Multiplayer 双端同步验证。
