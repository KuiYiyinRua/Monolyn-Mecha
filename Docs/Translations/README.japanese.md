# Monolyn: Mecha · 0.9.4

Monolyn Raceに光を動力とする地上ユニット6種を追加します。イモータル、ストーカー、コロッサス、ガーディアン、リーヴァー、ディスラプター。4種のメカは入植者の操縦またはメカニターによる無人操縦に対応し、2種の構造体はメカニターが制御します。バージョン：0.9.4。

## メカニターへ転移

全6種に専用の転移ボタンを追加。同じマップでは光の最大容量の30%、別マップやキャラバンからは50%を消費します。ストーカーとガーディアンは同率の構造体エネルギーを使用します。メカニターのメニューから、接続が残っている取り残された機体も呼び戻せます。メカニターがマップ上にいる必要があり、エネルギー不足や安全な着地点がない場合は消費しません。大型機体のキャラバン入場時の範囲外配置も修正しました。

## ガーディアン：シールドフィールド

帯域幅を2使用。専用の種子備蓄は最大30個で、スライダーで目標量を0～30個に設定し、入植者による自動運搬・補充を切り替えられます。種子5個で半径8マス、持続30秒のシールドを即座に展開し、ガーディアンと共に移動します。境界に触れた敵の弾は50%の確率で来た経路へ反射され、残りは通過します。味方の弾には影響しません。複数のシールドを重ねることができ、各シールドが独立して判定します。瞬間着弾のビームと近接攻撃は反射しません。

## 無人操縦

空の機体を、同じマップにいる空き帯域幅の十分なメカニターに接続します。必要帯域幅はイモータル4、コロッサス6、リーヴァー6、ディスラプター5。メカの制御グループに入り、指揮範囲内で徴兵、移動、攻撃を指示できます。光は引き続き消費します。操縦者の搭乗または接続解除で帯域幅を解放します。新規製造にも対応する空き帯域幅が必要で、製造所のメカニターに接続されます。

## 自爆と緊急脱出

操縦可能な4種に「自爆」を追加。結果を確認してから、50マス以内かつ視線の通る有効な着地点を選びます。操縦者は自分の装備・所持品と共に飛び出し、機体は即座に死亡・爆発して残骸を残しません。機体の貨物は消滅します。爆発は半径8マス、基本ダメージ80（ディスラプター85）、装甲貫通80%で、味方や建物も巻き込みます。赤い爆発範囲から離れた着地点を選んでください。近距離への着地は危険です。空の機体は確認直後に爆発し、帯域幅を解放します。確認や着地点選択のキャンセルでは爆発しません。

前線火力、機動戦、シールド支援、輸送を組み合わせられます。画像は旧版のゲーム内実演です。現在の数値と追加機能は本文を参照してください。

## イモータル · 前線の装甲機

シールド500。2発のミサイルはそれぞれ中心と上下左右の計5マスに10ダメージ。有人操縦、または帯域幅4の無人操縦に対応します。
![Monolyn Mecha](https://images.steamusercontent.com/ugc/12589577182004703314/968886AACCE76025368BFCB552D883F75E1EAF8B/)

## ストーカー · 高速機動

帯域幅2。双連レーザーとブリンクを使用。自動戦闘と自動ブリンクを個別に切り替えられ、運搬、掃除、消火も行えます。
![Monolyn Mecha](https://images.steamusercontent.com/ugc/11915945897327046556/131C9095258E1A543B42A5BC1B9AA9785A3A5791/)

## コロッサス · 双連掃射

シールド200。2本の掃射ビームが各21ダメージを十字5マスに与えます。壁を越え、移動中も射撃可能。無人操縦は帯域幅6。
![Monolyn Mecha](https://images.steamusercontent.com/ugc/12205559618903829612/45310D199D62877569D49AB4279471CD05823682/)

## ガーディアン · シールド支援

帯域幅2。連続レーザーで攻撃し、味方のシールドを回復。自動戦闘と自動回復は個別に設定でき、手動回復や種子を使う反射シールドにも対応します。
![Monolyn Mecha](https://images.steamusercontent.com/ugc/15217843184345479861/A28999F48C38F2DEDBD13589597C97B065D31F05/)

## リーヴァー · 重砲撃

弾倉10発、射程45マス。光から弾薬を自動製造し、範囲攻撃で建物に追加ダメージを与えます。無人操縦は帯域幅6。
![Monolyn Mecha](https://images.steamusercontent.com/ugc/12982748170061290114/2229723A6B9E273127444E71ACF99FAF40DB8505/)

## ディスラプター · 追尾光球

光球は5秒持続、毎秒8マスで移動し、0.25秒ごとに10ダメージ、最後の爆発は28ダメージ。光球維持中は機体が移動できません。無人操縦は帯域幅5。
![Monolyn Mecha](https://images.steamusercontent.com/ugc/12480251011735394709/A0BF373BEA033B81715C8F123EB8B89BBCEF2A14/)

## 貨物・旅・自動戦闘

積載量：イモータル500kg、コロッサス800kg、リーヴァー2000kg、ディスラプター600kg。4種は無人・有人・接続済みの各状態でキャラバンの動物欄から選択可能。メカニターは留守番できますが、操縦席の外の入植者が1人以上必要です。

全6種は有効な操縦者または接続済みメカニターがいれば、接続された塔を往復できます。操縦者・貨物・接続を保持。エネルギーとネットワーク制限が適用され、大型機による過負荷時は回復後に再選択してください。出口が塞がっていれば元のマップに残ります。

自動戦闘は初期オフ。コロッサスは距離を取り、他3種は追撃後に停止して射撃。手動移動を優先し、手動攻撃または停止で自動戦闘を解除します。
![Monolyn Mecha](https://images.steamusercontent.com/ugc/14583897241280851335/E044B67A55D44AD4D8481505D189E1D5979E2E5E/)

## 製造・修理・敵襲

研究後、接続したメカニターと空き帯域幅を用意し、Construct Formatorで材料と光を使って製造します。機体の自動修理とメカニターの鍛冶作業を有効にすると修理できます。敵対するUrielCultとRaphaelCultの戦闘襲撃には6種が出現し、部隊予算の最大半分を使用します。敵メカには同派閥の操縦者が乗り、自身の光を消費します。
![Monolyn Mecha](https://images.steamusercontent.com/ugc/13286242205039120716/D6208B33079CD4792200948384EB5467D58B4B34/)

## 前提MOD・言語・マルチプレイ

RimWorld 1.6 / 1.7、Harmony、Humanoid Alien Races、Monolyn Raceが必要。前提MODの後に読み込みます。構造体と無人操縦にはBiotechが必要です。簡中・英・日・仏・露の5言語とMultiplayer互換（1.6のみ）に対応。更新後は全員が完全なMODを揃えて再起動してください。
