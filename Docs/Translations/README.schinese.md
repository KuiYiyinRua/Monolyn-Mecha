# Monolyn: Mecha · 0.9.3

为墨诺灵种族添加六种以光芒为能源的地面单位：不朽、追猎者、巨像、守护者、掠夺者和禁断者。四种战甲支持殖民者驾驶或机械师无人驾驶，两种构装体由机械师控制。当前版本：0.9.3。

## 折跃至机械师

六种机械体新增专属折跃按钮：同地图消耗自身满容量30%的光芒，跨地图或从远行队召回消耗50%；追猎者和守护者使用等比例构装体能源。机械师菜单可召回仍保留绑定的掉队单位。机械师须在地图上，能源不足或附近无安全落点不扣费。修复大型机体远征入图时因边界越界而掉队的问题。

## 守护者：护盾立场

占用2点带宽。独立种子储备最多30个，可用滑条设置0–30个目标储量，并切换是否允许殖民者自动搬运装填。每次消耗5个种子，立即展开半径8格、持续30秒的护盾，随守护者移动。敌方投射物触及边界时有50%概率原路反弹，另外50%继续穿过；友方投射物不受影响。多个守护者的护盾允许重叠，各自独立判定。瞬发光束与近战不在反弹范围内。

## 无人驾驶

空舱战甲可绑定同地图且有足够可用带宽的机械师：不朽4、巨像6、掠夺者6、禁断者5。绑定后加入机械体控制组，可在机械师指挥范围内征召、移动和攻击，仍消耗光芒。驾驶员登机或主动解除绑定会释放带宽。新制造战甲也需要相应可用带宽，并绑定塑造所的机械师。

## 自爆与紧急弹射

四种可驾驶战甲均有「自爆」按钮。先阅读并确认后果，再为驾驶员选择50格内、视线可达的有效落点。驾驶员带着自己的装备和随身物品飞出，机甲立即死亡并爆炸，不留尸体；机甲货舱内的货物销毁。爆炸半径8格、基础伤害80（禁断者85）、穿甲80%，会伤及友军和建筑。落点应远离红色爆炸圈，近处落地仍可能受伤。空舱确认后立即自爆并释放带宽；取消确认或选点不会引爆。

## 不朽 · 正面重装

500点护盾。双发导弹每枚10伤害，覆盖中心与上下左右共五格。可由驾驶员操作，或使用4点带宽无人驾驶。

## 追猎者 · 高速机动

占2点带宽，双激光配合闪现。自动战斗、自动闪现可分别切换，也能搬运、清洁和灭火。
![Monolyn Mecha](https://images.steamusercontent.com/ugc/11915945897327046556/131C9095258E1A543B42A5BC1B9AA9785A3A5791/)

## 巨像 · 双束扫射

200点护盾，双束激光每束21伤害，落点覆盖五格十字。可跨越墙体、移动射击；无人驾驶占6点带宽。

## 守护者 · 护盾支援

占2点带宽，以持续激光作战，并恢复友方护盾。自动战斗、自动补盾分别控制，也可手动补盾或消耗种子展开反弹护盾。

## 掠夺者 · 重型轰炸

10发弹仓，射程45格，可消耗光芒自动制弹。范围轰炸对建筑有额外伤害；无人驾驶占6点带宽。
![Monolyn Mecha](https://images.steamusercontent.com/ugc/12982748170061290114/2229723A6B9E273127444E71ACF99FAF40DB8505/)

## 禁断者 · 追踪光球

光球持续5秒，以8格/秒移动，每0.25秒造成10伤害，最终爆炸28伤害。维持光球期间机体不能移动；无人驾驶占5点带宽。

## 货物、远行与自动战斗

载重：不朽500kg、巨像800kg、掠夺者2000kg、禁断者600kg。四种战甲在远征队动物栏中选择，空舱、有人驾驶、绑定机械师均可，机械师可留家；仍需一名舱外殖民者带队。

六种机甲有可用驾驶员或绑定机械师时，可通过已连接的灯塔往返，保留驾驶员、货物和绑定。需要能源及可用的灯塔网络；大型机甲可能造成超载，恢复后重新选择。出口无空地时留在原图。

自动战斗默认关闭；巨像拉开距离，其他战甲追击后停下射击。手动移动优先，手动攻击或停止关闭自动战斗。
![Monolyn Mecha](https://images.steamusercontent.com/ugc/14583897241280851335/E044B67A55D44AD4D8481505D189E1D5979E2E5E/)

## 制造、维修与敌袭

完成研究后，在构造体塑造所投入材料与光芒制造，需要绑定机械师及可用带宽。开启战甲自动维修并给机械师安排锻造工作，可自动修复机体。敌对乌列尔与拉斐尔教团的战斗袭击可带六种机甲，最多占一半编组预算；驾驶式敌机带同派系驾驶员并使用自身光芒。
![Monolyn Mecha](https://images.steamusercontent.com/ugc/13286242205039120716/D6208B33079CD4792200948384EB5467D58B4B34/)
