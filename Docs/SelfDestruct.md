# 自爆与紧急弹射（0.9.0）

不朽、巨像、掠夺者、禁断者均有独立的「自爆」按钮。守护者和追猎者没有驾驶舱，因此不增加此技能。

## 操作

1. 选中属于玩家的机甲，点击「自爆」。窗口会说明机甲、货舱和附近单位的损失。
2. 有驾驶员时，点击「确认并选择弹射落点」，选择 50 格以内可见、可通行且有视线的格子。白圈表示弹射射程，红圈表示爆炸半径。选择落点之前不会发生任何游戏状态变更；右键或 Esc 可以取消。
3. 驾驶员以原版跳跃飞行方式弹出，机甲在同一次指令内立即死亡并爆炸。健康且没有精神崩溃的驾驶员落地后处于征召状态，可继续指挥。
4. 无驾驶员时，窗口明确提示无需选点；确认即自爆。无人驾驶绑定会解除并释放带宽。

## 后果与数值

- 弹射半径 **50 格**，包含恰好 50 格；不能选择自身格、地图外、迷雾、不可落脚或视线被遮挡的位置。
- 爆炸半径 **8 格**，基础伤害 **80**，穿甲 **80%**（RimWorld 内部值 `0.8`），不随距离衰减。使用原版 Bomb 爆炸，其遮挡、伤害类型和目标倍率仍遵循原版规则。
- 会伤害范围内的友军、敌人和建筑。请选择红圈外的落点；近处落地仍可能被传播中的爆炸波击中。
- 机甲死亡后清除尸体，没有可复活或拆解的残骸。机甲货舱中的货物销毁；驾驶员自身装备、随身物品和身份保留。
- 机甲没有光芒或禁断者正在释放光球时，也可进行紧急自爆。仅对玩家自己的、已生成在地图上且尚未死亡的机甲开放。驾驶员已经死亡时禁止该操作。

## 联机执行边界

确认窗口、取消、目标高亮和选点均为本地 UI。可变更游戏状态的唯一入口为 `MechaSelfDestruct.Execute(Map, Pawn_Immortal, expectedPilotId, IntVec3)`，由可选 Multiplayer 程序集同步。核心程序集不依赖 Multiplayer。

原版 MP 已有原生跳跃/飞行支持，但不覆盖本模组的普通 `Command_Action` → 确认回调 → 目标回调。因此仅注册上述执行器，避免同步整个窗口或重复登记原版行为。该入口重新验证地图、所属派系、驾驶员身份及落点；换驾驶员、已下机、重复点击或另一客户端先引爆时，过期指令安全失效。

执行顺序为：停止驾驶员原任务 → 将真实驾驶员转入原版 `PawnFlyer` 容器 → 解除机械师绑定 → 销毁货物 → 原生死亡事件 → 清除尸体 → 原生爆炸。随机数只在共享执行/模拟中产生，显示窗口和目标预览不修改随机状态。飞行及飞行中的驾驶员由原版存档系统保存。
