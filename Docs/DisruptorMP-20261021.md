# 禁断者联机修订：0.9.3 本地部署

用户确认禁断者是此次实际游戏中的触发源，要求兼容现有 MP 本体与兼容包，并将各项基础伤害增加 5。随后明确要求“先调整，先不部署”。

## 证据与定位限度

Desync-533 首差在 tick 4157216、轨迹 4210：主机的 Explosion1234113 先调用伤害角度随机数，客户端的 Explosion1234112 先创建爆炸战斗日志。前一条轨迹的随机状态相同。日志证明双方爆炸处理路径已经不同，但截断记录没有保留这两枚 Explosion 的创建来源，不能单凭该包证明每个爆炸都属于禁断者，也不能把 530、531、532 的现象全部归因于它。

禁断者原实现直接使用 GenExplosion.DoExplosion，建立延后传播的独立 Explosion，并保存一份当前地图的排除名单。本次将该攻击改为光球到期时直接结算，避免继续依赖这条延迟对象路径。这是针对用户复现的兼容修订，尚不是双端复现后确认通过的根因闭环。

## 实现

- 脉冲、终爆都先收集完整范围内的目标，再按 ThingID 排序、去重，每个多格目标每轮只承受一次伤害。
- 终爆在光球第 300 tick 一次结算；不生成原生 Explosion，不再跨后续 tick 传播。这是明确的行为变化。保留半径 5、无衰减、仅敌方目标、原生伤害/护盾/护甲/建筑倍率、战斗日志、受伤硬直、爆炸热量与声音。
- Fleck 和声音使用异常安全的 Rand Push/Pop；实际伤害继续使用共享模拟随机流，不包裹整张地图或隐藏随机差异。
- 保留已保存的光球年龄、坐标、施法者和目标引用；没有修改存档字段名。已有旧 Explosion 不会被迁移或删除。
- 保留现有可选 MP 适配的攻击、停止、自动开火和自毁同步入口，不重复注册；修订位于机甲本体，不要求 MP 兼容包提供新的 Harmony 补丁。母体 ASEL 的其他联机兼容仍由已有适配负责，本次不声明整个 ASEL 可脱离兼容包运行。

## 构建与部署边界

待部署 Def、语言和 About 位于 `Source/RuntimeOverrides`。`Build.ps1` 在两项目成功构建后将它们复制到指定 OutputRoot。用户随后授权本地部署；确认无游戏进程后，16 个候选文件已复制到正式目录并逐项校验哈希，其他 281 个运行文件保持原样。备份位于 `BuildValidation/DisruptorMP-20261021/DeploymentBackup`，明细见 `deployment.json`。

独立构建目录：`BuildValidation/DisruptorMP-20261021/Candidate`。应使用这一目录中的 DLL、Def、语言与版本文件作为同一套更新，不能只替换 DLL。直接运行无 OutputRoot 的 Build.ps1 会输出到正式模组目录，因此本轮始终指定独立目录。

本轮只进行编译、产物反编译、XML/数值和正式文件哈希核验；不启动游戏。仍需双方更新并重启后的禁断者专项战斗、活动光球读档/重连验证，才能确认失同步已消除。
