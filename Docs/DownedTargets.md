# 倒地目标：自动过滤、手动允许 · 2026-10-25

不朽者的独立武器扫描原先缺少倒地过滤，共用射击校验又同时服务于自动和手动指令。本修订将可命中条件与自动索敌条件分开：六种机体的自动索敌排除倒地敌人，同时保留手动补刀。

四种战甲使用 `CanAutoShoot` 排除倒地敌人；`SetAttackTarget` 记录目标是否来自手动攻击，原有 `MechaActions.Attack` 同步执行器设置该标记。自动目标倒地后取消后续攻击，手动目标允许继续攻击。停止、重新自动选敌、切回自动战斗会清除手动许可。新标记写入原生存档；没有该字段的旧档默认按自动目标处理，手动命令可以重新指定。

## 同类路径检查

| 单位/路径 | 处理 |
|---|---|
| 不朽者 `CanShootFrom` / `TickWeapon` | 通用可射击条件允许倒地；自动扫描和自动续射单独排除倒地，手动双发正常。 |
| 巨像 `CanShootFrom` / `TickWeapon` | 同样区分自动和手动；手动瞄准倒地目标后可启动扫射。 |
| 掠夺者 `CanShootFrom` / `TickWeapon` | 同样区分自动和手动；手动炮击倒地目标正常。 |
| 禁断者 / `Thing_DisruptorOrb` | 光球保存自身的手动目标，允许追踪并伤害该倒地目标；目标失效后自动重选仍排除倒地，不继承手动许可。 |
| 追猎者 `ValidEnemy` / 原生攻击 Verb | 自动过滤原本正确，原生手动攻击也可对倒地目标开火；保持代码并回归验证。 |
| 守护者 `ValidEnemy` / `AttackTick` | 自动过滤保持；持续光束只对当前玩家强制 `AttackStatic` 的同一目标放行倒地攻击，普通 Wait 或自动任务不能绕过。 |
| 四战甲共用 `MechaCombatAI` | 保留倒地过滤；自动写入武器目标或切回自动战斗时清除手动标记。 |

已经发射的弹丸及巨像已经开始的定点扫射仍按原有范围伤害规则结算。禁断者仅对明确手动指定的倒地目标放行追踪和伤害，其自动重选和对其他倒地 Pawn 的既有过滤保留。
