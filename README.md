# 墨诺灵机甲与构装体 · 0.9.0

[简体中文](Docs/Translations/README.schinese.md) | [English](Docs/Translations/README.english.md) | [日本語](Docs/Translations/README.japanese.md) | [Français](Docs/Translations/README.french.md) | [Русский](Docs/Translations/README.russian.md)

为墨诺灵种族添加六种以光芒为能源的地面单位：不朽、追猎者、巨像、守护者、掠夺者和禁断者。四种战甲支持殖民者驾驶或机械师无人驾驶，两种构装体由机械师控制。当前版本：0.9.0。

## 守护者：护盾立场

占用2点带宽。独立种子储备最多30个，可用滑条设置0–30个目标储量，并切换是否允许殖民者自动搬运装填。每次消耗10个种子，立即展开半径8格、持续30秒的护盾，随守护者移动。敌方投射物触及边界时有50%概率原路反弹，另外50%继续穿过；友方投射物不受影响。多个守护者的护盾允许重叠，各自独立判定。瞬发光束与近战不在反弹范围内。

## 无人驾驶

空舱战甲可绑定同地图且有足够可用带宽的机械师：不朽4、巨像6、掠夺者6、禁断者5。绑定后加入机械体控制组，可在机械师指挥范围内征召、移动和攻击，仍消耗光芒。驾驶员登机或主动解除绑定会释放带宽。新制造战甲也需要相应可用带宽，并绑定塑造所的机械师。

## 自爆与紧急弹射

四种可驾驶战甲均有「自爆」按钮。先阅读并确认后果，再为驾驶员选择50格内、视线可达的有效落点。驾驶员带着自己的装备和随身物品飞出，机甲立即死亡并爆炸，不留尸体；机甲货舱内的货物销毁。爆炸半径8格、基础伤害80、穿甲80%，会伤及友军和建筑。落点应远离红色爆炸圈，近处落地仍可能受伤。空舱确认后立即自爆并释放带宽；取消确认或选点不会引爆。

## 六种单位，各司其职

组合前线火力、机动战斗、护盾支援和运输。以下为游戏内功能演示图；图片来自早期版本，当前参数与新增功能以文字说明为准。

## 不朽 · 正面重装

500点护盾。双发导弹每枚10伤害，覆盖中心与上下左右共五格。可由驾驶员操作，或使用4点带宽无人驾驶。

![不朽 · 正面重装](https://images.steamusercontent.com/ugc/12589577182004703314/968886AACCE76025368BFCB552D883F75E1EAF8B/)

## 追猎者 · 高速机动

占2点带宽，双激光配合闪现。自动战斗、自动闪现可分别切换，也能搬运、清洁和灭火。

![追猎者 · 高速机动](https://images.steamusercontent.com/ugc/11915945897327046556/131C9095258E1A543B42A5BC1B9AA9785A3A5791/)

## 巨像 · 双束扫射

200点护盾，双束激光每束21伤害，落点覆盖五格十字。可跨越墙体、移动射击；无人驾驶占6点带宽。

![巨像 · 双束扫射](https://images.steamusercontent.com/ugc/12205559618903829612/45310D199D62877569D49AB4279471CD05823682/)

## 守护者 · 护盾支援

占2点带宽，以持续激光作战，并恢复友方护盾。自动战斗、自动补盾分别控制，也可手动补盾或消耗种子展开反弹护盾。

![守护者 · 护盾支援](https://images.steamusercontent.com/ugc/15217843184345479861/A28999F48C38F2DEDBD13589597C97B065D31F05/)

## 掠夺者 · 重型轰炸

10发弹仓，射程45格，可消耗光芒自动制弹。范围轰炸对建筑有额外伤害；无人驾驶占6点带宽。

![掠夺者 · 重型轰炸](https://images.steamusercontent.com/ugc/12982748170061290114/2229723A6B9E273127444E71ACF99FAF40DB8505/)

## 禁断者 · 追踪光球

光球持续5秒，以8格/秒移动，每0.25秒造成5伤害，最终爆炸23伤害。维持光球期间机体不能移动；无人驾驶占5点带宽。

![禁断者 · 追踪光球](https://images.steamusercontent.com/ugc/12480251011735394709/A0BF373BEA033B81715C8F123EB8B89BBCEF2A14/)

## 货物、远行与自动战斗

载重：不朽500kg、巨像800kg、掠夺者2000kg、禁断者600kg。四种战甲可运输、参与远行及携驾驶员光芒迁移。自动战斗默认关闭，可在有人或无人驾驶运行时开启：巨像会拉开距离，其他三种追到射击位置后停下攻击。手动移动优先，手动攻击或停止关闭自动战斗。

![货物、远行与自动战斗](https://images.steamusercontent.com/ugc/14583897241280851335/E044B67A55D44AD4D8481505D189E1D5979E2E5E/)

## 制造、维修与敌袭

完成研究后，在构造体塑造所投入材料与光芒制造，需要绑定机械师及可用带宽。开启战甲自动维修并给机械师安排锻造工作，可自动修复机体。敌对乌列尔与拉斐尔教团的战斗袭击可带六种机甲，最多占一半编组预算；驾驶式敌机带同派系驾驶员并使用自身光芒。

![制造、维修与敌袭](https://images.steamusercontent.com/ugc/13286242205039120716/D6208B33079CD4792200948384EB5467D58B4B34/)

## 前置、语言与联机

RimWorld 1.6、Harmony、Humanoid Alien Races、Monolyn Race；本模组在前置之后加载。构装体和无人驾驶使用Biotech机械师系统。内置简中、英、日、法、俄五语，附带可选Multiplayer适配，支持种子滑条、搬运开关、护盾、绑定和自爆同步。更新后重启游戏，联机全员同步完整模组。新功能已完成隔离单机、读档及本机双端验证；不代表所有整合包和异步多地图环境均已验证。
