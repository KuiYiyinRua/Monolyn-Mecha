# 墨诺灵机甲与构装体

## 墨诺灵敌袭（0.7.0 · 2026-10-17）

Uriel 与敌对状态下的 Raphael 袭击可以携带本扩展的六种机甲。其他派系、友军增援、商队、据点守军、原版机械集群和猎杀人类动物事件不会因此获得这些单位。

战斗点数为：守护者 180、追猎者 400、不朽 900、禁断者 1100、掠夺者 1200、巨像 1600。四种驾驶战甲的点数已包含一名 120 点的墨诺灵步枪兵驾驶员。敌袭战甲满光芒入场，掠夺者带 8 枚导弹，后续射击与制造继续消耗自身储备；守护者携带 600 光芒用于补盾。敌机无法从玩家光芒网络充电。

机甲最多占用一次袭击预算的一半，重型机甲另有出场门槛和数量限制。驾驶员随战甲保存，离舱或机体被摧毁后继续归属原袭击队伍。详细参数及本轮验证范围见 [敌袭说明](Docs/EnemyRaids.md)。

## 自动战斗与驾驶迁移（2026-10-16）

追猎者的自动闪现沿剩余前进路径选点，避开门格；追击会完成穿门和绕墙路径，后撤不会先走向敌人。门口短暂出现的射界不会触发反复折返，无安全退路时原地射击。

巨像、不朽、掠夺者、禁断者新增「自动战斗」开关，默认关闭，需要可行动的驾驶员与光芒。巨像会追击、选择射击位置并拉开距离，移动时继续使用原有横扫武器；另外三种只追到可射击位置后停下攻击，不主动拉扯。手动移动优先，完成后恢复自动战斗；手动攻击或「停止」关闭自动战斗。「自由开火」（禁断者为「自动发射光球」）仍是原有的原地选敌开关。

四种机甲均可带着驾驶员使用「光芒迁移」，保留同一机体、驾驶员、货物和弹药，当前攻击按原有停止规则结束。目的地仍需同地图光芒网络覆盖和足够的落点空间；禁断者维持光球时仍不能迁移。可重复的隔离实机检查见 [测试说明](Tests/StalkerNavigation/README.md)。

## 护甲平衡（2026-10-14）

以依赖墨诺灵本体（Workshop `3742031864`）的 1.6 机械体定义为基准。以下是机体基础护甲百分比，与机体生命和护盾点数分别计算。

| 单位 | 定位 | 利器护甲 | 钝器护甲 | 热能护甲 |
|---|---|---|---|---|
| 守护者 | 轻甲 | 66% | 66% | 200% |
| 追猎者 | 轻甲 | 77% | 67% | 200% |
| 巨像 | 中甲 | 100% | 77% | 200% |
| 禁断者 | 中甲 | 100% | 77% | 200% |
| 掠夺者 | 重甲 | 135% | 87% | 200% |
| 不朽 | 超重甲 | 165% | 110% | 200% |

守护者对齐 `MNC_Inspector` 的 66%/66%；追猎者采用 `MNC_Excavator` 的 77%/67%，处于本体常规构装体范围。两种中甲将利器提高至 `MNConstruct` 的 100%，钝器取本体常规构装体的较高值 77%，形成轻甲与执法者之间的档位。掠夺者对齐 `MNC_Enforcer` 的 135%/87%。不朽在执法者基础上增加 30/23 个百分点，考虑其现有 500 护盾与单次伤害上限 50，保留穿甲武器的应对空间。所有单位的热防护对齐 `MNBaseConstruct` 的 200%。中甲与超重甲是本扩展拟定的平衡档位，并非本体已有分类。

此次只修改六种单位的护甲及相关说明。重启游戏后重新载入存档以加载新定义；联机各端需使用同一版 XML。已完成 XML 解析与改动范围静态校验，未进行本轮实机战斗或双端联机测试。修改前文件保存在 `BuildValidation/ArmorBalance-20261014/Before`，历史版本验证记录保留原样。

## 制造与操作

在墨诺灵科技树完成「构造工程 II」及「基础防御设施」，再以 **18000 信息**研究「不朽战甲」。研究位于本体构造工程 II 的右侧 `(9,0)`。

构造体成型器配方「打印：不朽」需要：**炼锻钢 180、灵脉回路 3、种子 30、光芒 25000**。制造时间 120000 tick（原速两天，受本体生产速度影响）。驾驶不占用机械师带宽。

选中战甲，使用「进入驾驶舱」指定殖民者。驾驶员到达战甲旁后登机。选中已驾驶的战甲可右键移动或攻击敌人，也可使用对应按钮。它按地面寻路，无法飞越障碍或进行穿梭机发射。

「装载货物」先选货物，再指定搬运者；「卸下货物」把货物卸到附近。组建远行队时先让驾驶员下机，然后在原版远行队界面同时选择殖民者和不朽；不朽可提供骑乘与驮运能力。

有人驾驶或空驾驶舱均可「光芒迁移」到**同地图**、已连接本体光芒网络的空地。迁移保留原战甲、驾驶员、装甲、护盾、光芒、货物和弹药，当前攻击按原有停止规则结束；产生 300 网络流量，迁移冷却 1000 tick（约 16.7 秒）。

- 参考相邻 `NivarianMotherShip` 的战舰直接操作边界、动作执行方法及持久化 `ThingOwner` 驾驶舱结构；不依赖或加载该项目的飞行/穿梭组件。
